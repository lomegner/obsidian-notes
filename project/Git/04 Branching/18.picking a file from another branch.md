
# 1.what is git restore --source command?

`git restore --source` specifies **which commit** to restore file(s) from.

## Basic usage:
```bash
git restore --source=<commit> <file>
```

## Examples:
```bash
# Restore file from 2 commits ago
git restore --source=HEAD~2 app.js

# Restore file from a specific commit hash
git restore --source=a1b2c3d index.html

# Restore from another branch
git restore --source=main config.yml
```

## Key point:
- Without `--source`, restores from the **staging area** (index)
- With `--source`, restores from **any commit** (or branch, tag, etc.)
- The file content is copied to your **working directory** (and staging area if `--staged` is also used)
