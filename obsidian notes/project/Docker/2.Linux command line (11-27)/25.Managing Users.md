`useradd -m lome`(user name)= adding a new user to the machine.
`usermod`= Changes settings for a user account that already exists.
`usermod -s /bin/bash josh`= this command changes the shell setting of user josh to bash.
shell is an program that takes our command and give it to linux to execute them, bash is a better and enhanced version of shell, `/bin/sh` represents shell and `/bin/bash` represents bash, `-s` in the command above is for changing shells setting of a specific user and you should be working with command as the root user.
`userdel josh`= deleting a specific user

`etc/passwd`= contains information of user accounts like their userID (first number), 
groupID (second number), their home directory name and what kind of shell they're using.

`etc/shadow`: contains passwords of users in encrypted form (only root user can access it)

imagine that your bash with root user is running, so since our ubuntu is running in a docker container, if we want to login as a different user in the same running container, what should we do, if we use docker start -ai lome(container name), whatever we do in one terminal, it will applied to the other terminal also but we want them to be independent of each other, so what we do, we run command below:

`docker exec -it 33ab62314d1e bash`

|                |                                               |
| -------------- | --------------------------------------------- |
| `docker exec`  | Execute a command inside a running container  |
| `-it`          | Interactive mode (so you can type)            |
| `33ab62314d1e` | Container ID(or name) (the running container) |
| `bash`         | The command to run (starts a shell)           |

if you wanted to login as the other user in the bash, we use command below:

`docker exec -it -u josh 33ab62314d1e bash`

which -u is for user specification and josh is the username.

while using command above for a specific container, that container should be running otherwise it won't work.

when we have logged in as a user except the root user and we type `cd ~`, we navigate to the home directory of that user.
