nano lome.txt (file name) = text editor and for manipulating contents of files.
cat lome.txt (file.name) = for showing content of small files
less lome.txt (file name) = for displaying contents of long files (if the command didn't work you should install it via `apt install less`)
head -n 5 lome.txt (file name) = shows first 5 rows of the specific file
tail -n 5 lome.txt (file name) = shows last 5 rows of the specific file
