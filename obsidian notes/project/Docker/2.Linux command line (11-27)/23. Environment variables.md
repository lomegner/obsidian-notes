environment variables are variables which get stored on the machine and not in your code, for example you have an api key which you don't want to be accessed by anyone, so you store it in an environment variable on your machine or server and then use that api key in your code via that environment variable, if you store inside a variable like `let` or `const`, the variable value can be accessed by anyone and it's bad for security of the application.

we have environment variable like PATH which helps for OS to find an app or program on our machine and its values are the paths like `usr/home` and so on.

`printenv`= display all of the environment variables on a linux machine.
`echo $PATH`(environment variable name)= display value of the specific environment variable.
`printenv PATH`(environment variable name)= same as echo$

`export LOME`= creates a new environment variable but it won't persist in a container session (we are not talking about running a new container like the scenario we had with the packages, if you close the terminal or use `exit` command to exit your current container, the environment variable will be vanished.)

for persistent environment variables, there is a file named `.bashrc` which is located inside our root home directory and it's hidden, for displaying it you should use `ls -a`

`echo LOME= hi>> .bashrc`= creates a persistent environment variable which will persist through container sessions.

when you create an environment variable in a session in `.bashrc`, until you reopen or reset that specific container, the environment variable isn't added to the `.bashrc`. so we use 
`source .bashrc` command to rerun the scripts in the `.bashrc` file i.e. reset the `.bashrc` file. so we can access our recently added environment variables in the current session of the container.

for displaying the environment variables stored inside the `.bashrc` we can only use 
`echo $LOME` and `printenv` won't work.

so always use `.bashrc` method and ignore `export` method.

and for seeing all of our environment variables first check `printenv` and then check content of the `.bashrc` file.

`exit`= exits the current container session, it's like closing an application or a game.
