process= an instant of running program

`ps`= shows all of the running applications an programs.

in the output of `ps` we have some terms like:
PID= process ID

TTY= the terminal which the program is getting run in it (pts/0 means the first terminal and pts/1 means the second terminal)

TIME: the amount of CPU time each program takes to run, if the system gets slow and we run `ps`, the time of one of the applications is high and we should kill that program.

`kill 17`(PID of a program)= kills a specific program

`sleep 5`= put the terminal in sleep for 5 seconds and you can't use it.

sleep 5 &= runs this program in the background and it doesn't disable the terminal.
