
redirection: changing the standard input and standard output (not simultaneously, it can be done separately)

standard input: keyboard
standard output: screen

there is no use case for changing the standard input but there are use case for changing the standard output.

for changing the standard output we use > (for changing the standard input we use <)

so when we have `echo hello world`, standard output is the screen so the `hello world` will be displayed on the screen but we can use `echo hello world > test1.txt` which stores 
`hello world` inside the `test1.txt`.

so `>` takes the output on the screen and can put it inside of a file.

common use cases:

- creating or editing a file with a small content as long as a single line:
  echo hello world (content)>test1.txt (file name)
- copying a file into another file:
  cat file1.txt (origin file) > file2.txt(destination file)
- concatenating two files together:
  cat file1.txt file2.txt >file3.txt
- soring output of a command in a file
  ls /etc/adduser.conf > file4.txt (file4.txt will contain the list of directories and files inside etc/adduser.conf)

for short content editing like as long as 1 line use `echo` and for longer one use nano.
