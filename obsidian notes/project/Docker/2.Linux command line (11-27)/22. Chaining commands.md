`mkdir test; cd test; echo schlampe`
(we separate them with ;)
in command above, if any of the commands fail, the other commands will function

if you want if any of the commands fail, the other commands doesn't work use `&&`.
`mkdir test && cd test && echo schlampe`
it will till if the operand doesn't fail, from the place the operand fails, the other operands won't work anymore.

`mkdir test || echo schlampe`
this command says if the left operand works, the right one won't work and if the left operand fails, the right operand will work.

if the chained command got too long, we can use this trick to move them in the next lines
mkdir test;\(then press enter)
cd test;\(then press enter)
echo schlampe
