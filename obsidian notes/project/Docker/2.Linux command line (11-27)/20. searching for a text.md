`grep hello (designated word) file.txt (destination file)`
shows word hello in a line which is used in the file.txt

for searching text without case sensitivity:
`grep -i hello file.txt`
finds Hello, hello, `hEllo`, `-i` is for case insensitivity

for searching a text inside multiple file:
`grep -i hello file1.txt file2.txt`
`grep -i hello file*`

for searching a specific text inside all of the files of a directory:
`grep -i -r hello lome`
 or
`grep -ir hello lome`
