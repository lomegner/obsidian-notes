
in linux we have a root directory and below that we have bunch of standard directories which are listed as below:
/: root directory
bin: binaries or programs
boot: files related to booting
dev: files needed to access devices
etc: configuration files
home: home directory of each user
root: root directory which is only for root user
lib: library files like software dependencies
var: files that get updated frequently like log files
proc: files that represent running processes.
