`ls -l`= shows list of the content of a directory with each content permissions and creator user and group.

directories start with d and files start with -, then 3 group with 3 members, which is rwx or -, r represents read, w represents write and represents execute, the first three (indeed we are talking about the first three after the first place) belongs to permissions the creator user has, the second three belongs to permissions that group has and the last three represents the permission the others have.

for changing permission we use `chmod` command, in this command `u` represents creator user,
`g` represents group and `o` represents `others`, `+` represents addition of a permission and `-` means subtraction of a permission.

so even when we a user create a file like `deploy.sh`, we can't run it, so we have to give execution permission to ourselves.

first give the permission:
`chmod u+x deploy.sh`

then run the file:
`./deploy.sh`
(for executing this file you always need `./` even if you're in the directory of the `deploy.sh`)

other sample of `chmod`:

`chmd og+x-w deploy.sh` (we have multiple files or `*.sh`)

if we don't supply one of u,g,o in the chmod, the permission will be applied to all of them:

`chmod +x deploy.sh`
