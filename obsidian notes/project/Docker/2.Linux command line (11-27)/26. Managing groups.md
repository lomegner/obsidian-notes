
Primary group determines ownership of new files you create; secondary groups grant you permission to access shared resources (like docker, sudo, or project folders) without changing your default file ownership behavior.

when we create a user, a group with the same name of the username will be created which that group will be the primary group of that user.

the primary group controls the file changing access and the secondary group will give you acess to use specific commands.

`groupadd developers`(group name) = creates a new group on the machine.

`/etc/groups`= place all of the groups with their ids are stored.

`usermod -aG developers(group name) josh(username)`= adding a user to a secondary group

`groups josh(username)`: displays groups of a specific user
