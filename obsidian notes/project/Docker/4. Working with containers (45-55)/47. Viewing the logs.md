`docker logs 6fe23`(container id):  displays everything a container has printed to the terminal (console output), helping you debug, monitor, and understand what's happening inside your container and it's good for container which are getting run in the background.

## Why It's Useful

| Without `docker logs`             | With `docker logs`           |
| --------------------------------- | ---------------------------- |
| Can't see what container is doing | See errors, requests, status |
| No way to debug crashes           | Find why container failed    |
| Blind to problems                 | Visibility into behavior     |


`docker logs -f myapp`: follow live logs

`docker logs -n 5 myapp`: logs last 5 lines

`docker logs -t myapp`: logs with timestamps
