`docker ps` = Running containers only
`docker ps -a` = All containers (running + stopped)

`docker run` = Runs  the container in foreground
`docker run -d` = Runs the container in background (detached)

`Without `-d` (foreground)
docker run nginx
Terminal is attached to container
Shows all logs
Can't type other commands
Press Ctrl+C to stop

`With `-d` (background)
docker run -d nginx
Returns container ID immediately
Terminal is free for other commands
Container runs in background

## When To Use Which

| Use case                         | Command                      |
| -------------------------------- | ---------------------------- |
| Running a web server permanently | `docker run -d nginx`        |
| Running a database               | `docker run -d postgres`     |
| Testing something quickly        | `docker run ubuntu`          |
| Debugging                        | `docker run -it ubuntu bash` |

`docker run --name lomejeenr`(container name): gives the container a name to run.
