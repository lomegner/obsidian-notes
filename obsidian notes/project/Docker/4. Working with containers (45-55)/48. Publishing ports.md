Expose instruction is useless and doesn't do anything, it just let you know this application uses port 3000 and even using `docker run -P lomejeener` which allegedly uses Expose under the hood, still won't run the application on our host machine and we should still use 
`docker run -p 3000:3000 lomejeener` to run application on our machine.

in the -p 3000:3000, the 3000 in the right should be the port of the application which is running in the container and 3000 in the left should be the port of the same address we have for our application in the container that we want on our host so if we have:

`http://localhost:3000` in the container and we typed:
`docker run -p 80:3000 lomejeener`
we should type:
`http://localhost:80`
in our host machine ( which is our machine) browser to run the application.
