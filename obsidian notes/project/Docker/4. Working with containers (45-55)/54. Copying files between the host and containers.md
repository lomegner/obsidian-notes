
`docker cp e456:/app/log.txt .`: copies log.txt from app directory with container with id of e456 into the current directory of our host (which is our machine) (the current directory is the directory and path we're pointing to it in terminal)

`docker cp source.txt e456:/app`:  copies `source.txt` from our host machine and transfers it to app directory of a container with id of `e456`.

it's useful when you have a file on a container and you want to have it on other containers, since you didn't know you're going to have such a file, you didn't create a volume and point it to your container, so we use this approach to share the certain file between other containers.

by the way, closing terminal doesn't stop a running container in the background (detached container), it only stops container running in the foreground.
