`docker container rm lomejeener`(container name): removing a container
`docker rm lomejeener`: same as above

`docker container rm -f lomejeener`: for when you have a running container and you want to delete it, you can either stop that specific container and remove it via `docker rm` or you can just use this command.

docker ps -a | grep lomejeener: we can use this command to check if a specific container exists still in our container list or not.
