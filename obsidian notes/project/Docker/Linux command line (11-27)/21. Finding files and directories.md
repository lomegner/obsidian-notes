find is like an advanced `ls` which shows all of the files and directories, even the recursive one in the supplied path or the current directory, you have filtering option for filtering the type of content and name of them.

find : list all of the directories and files and recursive one which we have in the current directory.
find /etc -type d= list all of the directories and recursive one which we have in the /etc.
(if we don't provide a path or /etc, it will list content of the current directory)
find /etc -type f= list all of the files and recursive one which we have in the /etc.
find /etc -name "\*.txt"= list all of the content in the /etc that it has .txt in its name.
find /etc -iname "\file*"= list all of the content in the /etc that it has file, File, fIle in its name, -i is for case insensitivity.

`ls -a`: list all of the current directory files and directories even the hidden ones.
