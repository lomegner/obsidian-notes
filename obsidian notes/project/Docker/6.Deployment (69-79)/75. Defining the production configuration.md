
`restart`: a property in our `docker-compose.yaml` file which controls if our code crushed on the server or the container stopped for any reason and crash, to restart on it, we usually set its value to `unless-stopped`, this value gives us this option that whenever the container stopped in the server, it run it automatically unless we have stopped the container manually and by deliberation and by using this property we don't need to `ssh` to server and run `docker compose up` manually.

we use this command in docker-compose file of our production and for all of our services:
```
restart: unless-stopped
```
