Deployment options:
single server: we deploy our database, backend and frontend to a single server.
cluster (multiple servers): you deploy your backend, frontend and database to multiple server, so if one of the servers is down, your site can be still running unlike the single server.

cluster is more complex and expensive to implement and we use `kubernetes` and `docker swarm` to manage our clusters. (`kubernetes` is more common)

### Single Server

┌─────────────────┐
│   Server 1      │
│   ├── App       │
│   └── Database  │
└─────────────────┘
If this dies → Everything dies

### Multi-Server (Cluster)

┌──────────┐ ┌──────────┐ ┌──────────┐
│ Server 1 │ │ Server 2 │ │ Server 3 │
│ ├── App  │ │ ├── App  │ │ ├── App  │
│ └── DB   │ │ └── DB   │ │ └── DB   │
└──────────┘ └──────────┘ └──────────┘
If one dies → Others still serve traffic
