
`CMD npm start`= shell version of CMD
`CMD ["npm","start"]`= execution format of CMD

use execution format of CMD due to its performance advantages it has.

CMD difference with RUN is, Tun runs the commands in the build-time but CMD runs the command in the run time.

`CMD`= It specifies what runs when you start a container from the image.

when you have Dockerfile as below:


```
FROM node:26-alpine3.22 
WORKDIR /app 
COPY . . 
RUN npm install 
ENV API_URL=https://api.myapp.com/ 
EXPOSE 3000 
RUN addgroup threesome && adduser -S -G thereesome lome 
USER lome
```
it fails when we wants to get built, because we have installed packages under the root user and now we want to login as lome user, if we change it to below:

```
FROM node:26-alpine3.22 
WORKDIR /app 
COPY . . 
RUN npm install 
ENV API_URL=https://api.myapp.com/ 
EXPOSE 3000 
RUN addgroup threesome && adduser -S -G thereesome lome 
USER lome
```

it won't get built still because for installing the packages we need root permission.

the workaround is:

```
FROM node:26-alpine3.22
RUN addgroup threesome && adduser -S -G threesome lome
USER lome
WORKDIR /app
COPY --chown=lome:lome . .
RUN npm install
ENV API_URL=https://api.myapp.com/
EXPOSE 3000
CMD ["npm", "start"]
```
so `--chown=lome:lome` says all of the files belong to user lome including the `package.json` which package installation takes place from there, so `RUN npm install` can work easily and without any issue.
