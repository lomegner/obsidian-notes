
sometimes your team member doesn't have access to dockerhuba nd you want to give them the image file so they can run it on their machine, first we should save the image on our machine and then give to them to load it on their machine.

`docker image save -o react-app.tar(file name which you want to save your image in it, it should be .tar file and .tar file is not specific to linux, all of the OSs can understands it) react-app:3(image name)`: saving docker image in the direcotory you're currently located in your terminal

`docker image load -i react-app.tar`: loading a image on your machine



`Note:` for your own personal projects, always create a dockerfile and always build images and check it to find issues, if you got added to a team and they had dockerfile, always build images and check if the application works fine in the container or not but if they didn't have any dockerfile for their project, don't do anything and don't make extra responsibility for yourslef.
