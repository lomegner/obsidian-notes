A dangling image is an untagged, unnamed image (showing as `<none>:<none>`) created when you rebuild an image with an existing tag — it wastes space but can be safely removed with `docker image prune`.
but these dangling commits might not show all the time and if you run `docker image prune` and they didn't get removed, you should removed all of the stopped container you have via 
`docker container prune`

`docker image rm docker-app`(image name or id): removes an specific image
if the image removed, please its container which runs this image and it's stopped now exists, so you have to delete that container first via `docker container rm lome` (container name or id).

you can delete dangling images and their containers one by one via:
`docker image rm` and `docker container rm`.
