`WORKDIR`= Sets the current working directory inside the container (if the directory doesn't exit it creates it) and all following commands (`COPY`, `RUN`, `CMD`) run from there.
COPY= Copies files from your computer into the image

we have such a command as `docker built -t lome .` , that `.` means look for the Dockerfile in the current directory we are located, so how it works, the docker engine only looks the current directory and content inside of it recursively to find the Dockerfile, it doesn't check outside of the current directory, so when we want to copy a content, we can't copy anything from outside of where Dockerfile is located, so Put your Dockerfile in the project root (outermost folder of your project).


ADD is like COPY but you can add files from a URL and the other difference is, if you add a compressed file to copy, it will uncompress it where it was supposed to copy it.

we can COPY multiple files or even a pattern like:

COPY lome.txt lome2.txt /app/(if you use multiple files you need to use / after end of the destination)
(what if there is no such a directory as /app)--> it creates a file named app not a directory, so always use WORKDIR to create a directory for you for copying your code or use an existing directory or make one by `mkdir` and then copy your code inside that directory, if you use a nonexistent directory name, it creates a file under that name and copy your code or content in that file.

if you have space inside name of your files you have to wrap them inside `[]`:

`COPY ["hello word.txt", "/app"]`

if you build a image with an existing image name, the new image will replace the previous image.

`package.json`: holds dependencies names and their version but the version installed on the machine may be different so we have `package-lock.json` which holds the precise version of the dependencies installed on our machine.

for running react app when you're inside your container linux, you have to run command below for specifying the ports:

`docker run -p 3000:3000 -it react-app sh`

`-p 3000:3000` is for specifying the port 3000 to the conatiner which our react app usually run on this port.
