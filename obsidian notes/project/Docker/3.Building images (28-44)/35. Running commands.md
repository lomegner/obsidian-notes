`RUN npm install`(command)= runs commands inside the container at image build time.

there is no difference in size and amount of time to build an image in 2 scenarios below:

scenario A: including `node_modules` inside your build context and not running `RUN npm install`

scenario B: ignoring the `node_modules` and running `RUN npm install`

meanwhile scenario B is better because when we include `node_modules` it may contains some binary data specific to the OS it was located and when we want to run the image in another OS, it may fail.
