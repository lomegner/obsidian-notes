navigate to dockerhub and sign-up and please sign-up with email and password because Gmail and GitHub sign-in can become troublesome later, then create a repository like GitHub to add your images, then head to your terminal, you have a specific image with its specific tag to be pushed to your repository on dockerhub but where the docker should know which username and which repository the image should be pushed to, so you create a tag from your image with specification below:

`dockerhub username/repository name: build number`

so imagine you want to push `react-app:3` image to `hello` repository on dockerhub with username of `lomegner`, this is how the new tag looks like:

`docker image tag react-app:3 lomegner/hello:3`

so when you want to push `lomegner/hello:3` to dockerhub, the docker knows this image should be pushed to dockerhub with id of `lomegner` and `hello` repository.

after creating the new image tag, this is the procedure we complete for pushing the image on dockerhub:

1.`docker login`: for inserting the credentials.
2.`docker push lomegner/hello:3`
