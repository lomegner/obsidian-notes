docker always runs the container as the root user, running the container as the root user can makes security issues, so we have to create another user and log into the container as that user.

command for user creation on alpine (in ubuntu we have `useradd` and `groupadd` but in here we have `adduser` and `addgroup` which is because of the differences in distribution)

`RUN addgroup app (group name) && adduser -S -G app lome(username)`
`-S` is regular option for user creation and `-G` is for specifying a group to the user.

`USER lome`= Sets The User For Subsequent Instructions and It switches from root to a non-root user for security.
