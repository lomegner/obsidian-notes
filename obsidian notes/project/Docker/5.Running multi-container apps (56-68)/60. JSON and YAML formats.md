
JSON is for exchanging data over internet and YAML is for configuration files, we use JSON for data exchange because it's parsing is easier than YAML and we use YAML for configuration files because it's easier to understand.

```JSON
{
"name":"the ultimate docker course",
"price": 149,
"is_published": true,
"tags": ["software","devops"],
"author":{
"first_name": "Mosh",
"last_name": "Hamedani"
}
}
```

its equivalent in YAML is:

```YAML
---
name: The Ultimate Docker course
price: 149
is_published: true
tags:
 - software
 - devops
author:
 first_name: Mosh
 last_name: Hamedani   
```

the hierarchy get specified with indention not `{}` in YAML, there is no `""` for text identification, we specify array elements with a leading hyphen but we should have indentation to display that they are elements of an array and for objects we don't need `{}` and we can just add the object properties with indentations, and the `,` is removed between properties, the `---` in the beginning of the YAML demonstrates initiation f the file.

so this was the comparison between JSON and YAML.

we use use both `.YAML` and `.YML` file extension for a YAML file.
