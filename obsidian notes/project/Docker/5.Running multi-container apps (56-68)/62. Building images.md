
docker-compose like the docker engine( the commands we were running earlier) has the same commands.

`docker-compose build`: for creating images of the services we have in our docker-compose we use.

the naming convention for the images is :
`directory the docker compose is located/ name of the service`
so we have something like:
`vidly/frontend`
`vidly/backend`
`vidly/db`

after coding and for checking the docker containers, always rebuild the images so new change can be added to the image.
