
we can run tests of our app sections like front-end, back-end locally and also in the container, we should run the tests in both places to see if there is any problem or not.

for running test in the container, we need a docker-compose file because we have to reuse the same image.

by running the test in the local environment we realize that our code doesn't have any problem and bug based on our development node version and by running tests in the container we can realize that our code has no problem with container node version and if we face any bug in the container we have to upgrade our node version of the Dockerfile.

```
version: "3.8"

services:
  frontend:
    build: ./frontend

    ports:
      - 3000:3000

  frontend-test:
    image: vidly-frontend

    command: npm test
    
   #front-end section tests

  backend:
    build: ./backend

    ports:
      - 3001:3001

    environment:
     DB_URL: mongodb://db/vidly

     command: ./docker-entrypoint.sh

  db:
   image: mongo:4.0-xenial

   ports:
     - 27017:27017

   volumes:
     - vidly:/data/db

volumes:
  vidly:
```
