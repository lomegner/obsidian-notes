for connecting a new made branch and its commits to a remote repository we use 
`git push -u origin lome(branch name)`

for removing the correspondent remote branch:

`git push -d origin lome (branch name)`

it gets used when we have merged our commits to master and we want to delete the branches.

so when we have a new branch, we have to use:
`git push -u origin lome(branch name)`
to create a correspondent branch in remote for it.
