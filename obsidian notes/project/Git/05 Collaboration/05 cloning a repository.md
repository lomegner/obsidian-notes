origin= remote repository
origin/master= master branch in the remote repository aka remote tracking branch
git clone address
you get address in the green code button of your GitHub repository in the code section and add it to this command.

git remote= shows our remote repository
git remote -v= shows address of our remote repositories
git branch -vv=
`git branch -vv` shows **local branches** with their **tracking remote branches** and **ahead/behind counts**, i.e. how many commits are ahead of the correspondent remote branch or you're behind.
